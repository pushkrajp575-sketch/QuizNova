# QuizNova – Quiz Application

## 1. Project Title

QuizNova – Python Quiz Application

## 2. Problem Statement

Problem 4 – Quiz Application

QuizNova is a Python-based quiz web application that allows users
to select a category and difficulty level, answer randomly
selected questions, calculate their score, view the final result,
and review the correct answers.
